# PlataA

Этот проект содержит прошивку для ESP8266, управляющую доступом к устройству через Telegram.

## Возможности
- Настройка Wi‑Fi и параметров бота через веб‑интерфейс.
- Управление пользователями: роли "админ" и "гость".
- Обмен сообщениями и заявками на доступ через Telegram.
- OTA‑обновление прошивки.
- Обмен статусами и командами между двумя платами по UDP и HTTP.

## Предложения по оптимизации
- Разнести большие функции на более мелкие для улучшения читаемости.
- Использовать `PROGMEM` для статических строк, чтобы экономить RAM.
- Проверить использование `String` и заменить на `String`/`char` буферы или `std::string`, чтобы избегать фрагментации памяти.
- Добавить обработку ошибок при работе с файловой системой и сетью.
- Стараться не использовать `delay`, заменяя его проверками времени через `millis`.
- Давать новым функциям и переменным имена русскими словами на латинице.
